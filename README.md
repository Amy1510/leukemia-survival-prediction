## What is this project?

This project models **overall survival (OS)** of patients diagnosed with Acute Myeloid Leukemia (AML),
using clinical and molecular data from 3,323 patients across 10 European hospital centres
(QRT Data Challenge 2025).

It compares a regularised Cox proportional hazards model against a Random Survival Forest (RSF),
and exposes the best model through an **interactive Streamlit application** designed for clinicians
and researchers.

> **Disclaimer** — This tool is for research and educational purposes only.
> It must not replace clinical judgement or be used for treatment decisions.

## Results

| Model | CV C-index | Test platform |
|---|---|---|
| RSF — Clinical only | 0.7162 | 0.65 |
| **RSF — Clinical + Molecular** | **0.7393** | **0.7524** |

The **C-index** (concordance index) measures how well the model ranks patients by survival time:
0.5 = random ranking, 1.0 = perfect ranking.

**Key findings:**
- Cytogenetic classification (ELN 2022) is the dominant prognostic feature (log-rank p < 10⁻⁵³)
- Molecular features (top-30 gene indicators + VAF statistics) add **+0.023** over clinical data alone
- Robust model selection via `pick_config` (minimising train/validation gap) improved test performance
- RSF outperforms regularised Cox PH by capturing non-linear interactions between variables

### 1. Clone the repository

```bash
git clone https://github.com/Machoudi-1/leukemia-survival-prediction.git
cd leukemia-survival-prediction
```

### 2. Install dependencies

```bash
poetry install
```

### 3. Add the data

The QRT 2025 dataset is not included in this repository.
See [`data/README.md`](data/README.md) for download instructions.

Place the files as follows:

```

├── X_train/
│   ├── clinical_train.csv
│   └── molecular_train.csv
├── X_test/
│   ├── clinical_test.csv
│   └── molecular_test.csv
```

```bash
poetry run jupyter notebook notebooks/survival_analysis.ipynb
```

Run all cells. This trains both models and saves them to `models/`.

### 5. Launch the Streamlit app

```bash
poetry run streamlit run app/app.py
```

## Streamlit application

The app allows clinicians and researchers to explore survival predictions interactively:

- Enter a patient's **cytogenetic risk group** (ELN 2022 classification)
- Enter **hematological markers** at diagnosis (BM_BLAST, WBC, ANC, MONOCYTES, HB, PLT)
- Get a **predicted survival curve** with 1-year and 3-year probabilities
- Read a **plain-language clinical interpretation** of the result
- View **which markers matter most** and how this patient compares to normal reference ranges

## Methodology

### Data

- 3,323 AML patients, 10 European hospital centres (QRT Data Challenge 2025)
- Clinical features: 6 continuous hematological markers + cytogenetics + center
- Molecular features: mutation-level data (gene, effect, VAF, depth) — aggregated to patient level
- Target: OS_YEARS (survival time) + OS_STATUS (1 = death, 0 = censored)
- Censoring rate: ~48%

### Pipeline (no data leakage)

```
Raw data
   ↓
Cytogenetic classification (ELN 2022)
   ↓
Missing value filtering (rows with > 3 missing values removed)
   ↓
Train / test split (5-fold CV, stratified on event)
   ↓
log1p transformation → StandardScaler → KNN imputation  ← fitted on train only
OneHotEncoder for categorical variables                  ← fitted on train only
   ↓
GridSearchCV — Cox PH vs Random Survival Forest
   ↓
Robust model selection via pick_config (minimising train/val gap)
   ↓
Final evaluation on held-out test set
```

### Molecular feature engineering

The raw molecular dataset (one row per mutation) is aggregated to one row per patient:
- **Mutational burden**: N_MUT, N_GENES
- **VAF / depth statistics**: VAF_MEAN, VAF_MAX, DEPTH_MEAN, DEPTH_MAX
- **Top-30 gene indicators**: binary presence/absence for the 30 most frequently mutated genes
- **Top-10 mutation effect counts**: number of mutations per effect type per patient

K=30 was selected via cross-validation (K=10, 20, 30 yielded similar CV scores ~0.740).
